# Pakenham Hospital – Smart Patient Management System (Prototype)

## Overview
This repository contains a **prototype Patient Management System (PMS)** for **Pakenham Hospital**, developed as part of the SENG205 Software Engineering project at Kent Institute Australia.  

The system demonstrates how patient enrolment, appointment scheduling, attendance tracking, and support services can be modernised using a lightweight web-based prototype built with **HTML, CSS, and JavaScript**.  

---

## Features Implemented
- **Patient Registration & Login**
  - Create new patient accounts
  - Authenticate with stored credentials (localStorage-based)

- **Appointment Booking & Cancellation**
  - Book and cancel appointments
  - Conflict detection to prevent overlapping bookings

- **Waitlist Management**
  - FIFO (first in, first out) promotion when slots free up

- **Attendance Tracking**
  - Reception can mark check-ins
  - Alerts when attendance falls below threshold

- **Support**
  - Rule-based **Chatbot** to handle FAQs
  - **Ticketing system** for patient queries

- **Admin Panel**
  - Manage users, policies, and practitioner availability
  - Role-based access control (patients cannot access admin UI)

---

## Technology Stack
- **HTML5** – Interface layout  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6)** – Application logic & localStorage persistence  
- **GitHub** – Version control, branching, and repository hosting
